# 知识数据中台 · 管理后台

出版社高质量数据集平台 — 管理后台 demo（Vue 3 + Element Plus + ECharts 单文件应用）。

## 功能概览

| 模块 | 页面 | 说明 |
|------|------|------|
| 总览大屏 | 总览大屏 | 数据中台全链路流转状态，7 节点流程图 + 5 张 ECharts 图表 |
| 数据资产 | 资产目录 / 资产编目 / 分级分类 / 标签体系 | 资源元数据管理、分类定义、标签运营 |
| 资源管理 | 资源接入 / 原始资源库 / 成果库 | 文件上传、对象存储归档、结构化成果回溯 |
| 内容结构化 | 解析引擎 / 校准工作台 / 结构化审核 / 结构化成果 | PDF/Word→章节段落表格公式解析与校准 |
| 知识检索 | 全文检索 / 语义检索 / 分面导航 / 混合检索 | 统一检索入口，碎片化结果追溯原文页码 |
| AI 能力 | RAG 问答 / 模型网关 / Agent 工作台 / 提示词库 | 大模型接入、RAG 增强检索、Agent 编排 |
| 数据治理 | 元数据管理 / 数据质量 / 血缘分析 | 元数据采集、质量规则、全链路血缘追溯 |
| 安全合规 | 版权授权 / 权限管理 / 审计日志 / 异常预警 | 版权管控、RBAC 矩阵、Append-Only 审计 |
| 接口服务 | 数据网关 / 成果回流 / 运营反馈回流 | API 统一封装、加工平台成果回流、RAG 反馈分析 |
| 系统设置 | 系统设置 | 组织模式切换、存储引擎状态监控 |

## 技术架构

- **框架**: Vue 3 Options API + Element Plus
- **图表**: ECharts 5 (折线/饼图/柱状/词云)
- **数据总线**: 全局 `reactive` store (20+ 字段) 作为全站唯一真值源
- **口径一致性**: 8 大跨页指标统一从 `store.overview.*` 取值
- **验证**: Playwright headless 遍历 31 页，0 console error

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建工具。

- 通过左侧菜单切换 31 个功能页面
- 顶部通知栏、角色切换、全局搜索
- 所有交互数据联动 `store` 全局状态
